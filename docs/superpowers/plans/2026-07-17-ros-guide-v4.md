# Guide V4 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Réécrire le module Guide pour qu'il enseigne le modèle V4 et soit **dérivé de `ros-model.js`**, de sorte qu'il ne puisse plus jamais dériver.

**Architecture:** `Guide.jsx` redevient une coquille (~60 l.) = nav + aiguillage ; le contenu part en composants `pages/guide/` qui **lisent** le modèle au lieu d'écrire des faits. Le modèle gagne les 8 justifications manquantes (registres `source`/`convention`) et `DIM_META` (libellés de dimension). Un test-verrou rend impossible d'ajouter une voie sans son « pourquoi ».

**Tech Stack:** React 18 + Vite, Vitest. Aucune dépendance nouvelle (pas de jsdom, pas de testing-library).

**Spec de référence (source de vérité des textes) :** `docs/superpowers/specs/2026-07-16-ros-guide-v4-design.md` (commit `d1881f8`).

## Global Constraints

- **La ligne de partage (§3 de la spec)** : un **fait** — comptage, seuil, libellé, bande, palier, applicabilité, palier d'interprétation — n'est **jamais écrit** dans le Guide ; il est **lu** depuis `ros-model.js`. Seule la **prose conceptuelle** est écrite à la main. Verbatim spec §3.
- **Registres** : `justification` OBLIGATOIRE sur toute voie ; **au moins un** de `source` (texte opposable) / `convention` (arbitrage du référentiel) ; les deux peuvent coexister. Verbatim spec §4.
- **Mono-entreprise · déterministe · toute logique de score dans `ros-engine.js`** (le Guide ne calcule rien lui-même sauf via `aggregate`/`governanceCoef`). Verbatim CLAUDE.md.
- **Portée `DIM_META` volontairement limitée** : seul `GuideModele.jsx` le consomme. **Dashboard, Report et Assessment ne sont PAS migrés** (en prod, migration cosmétique, risque de régression pour zéro gain) → follow-up spec §11. Verbatim spec §4bis.
- **Ne pas déployer sans feu vert** (`/ros-ship`). Ne jamais toucher `backend/data/storage.json`.
- **Les 51 tests existants restent verts.** Commandes : `cd /home/Felfool/ros/frontend` ; test `npx vitest run` ; build `npm run build`.
- **`App.jsx` importe `Guide` par défaut depuis `./pages/Guide.jsx`** — la coquille DOIT conserver cet export default. Aucun changement de route. Verbatim spec §10.
